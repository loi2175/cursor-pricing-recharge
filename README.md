## 代充买到的到底是什么：¥5 是挂牌价，规格写的是“新号代充”

淘宝在售的那件商品，标题是“Cursor Pro会员月卡代充 Ultra会员订阅服务 写程式辅助工具代购 AI智能工具订阅”，标价 ¥5.00，店铺“互联蛙旗舰店”，物流 4.8、服务 4.7、商品描述 4.7。2026.10.20 的一条评价原文是：“颜色分类:【新号代充】15刀/月Premium版会员 服务态度很好，很快回复，很快完成订单，赞！”

三个细节值得拆开看。

¥5 是商品挂牌价。同一商品按规格定价，不同规格对应不同价格，把它折算成“一折”或“5 元一个月”都不成立。

规格里写的是“新号代充”，字面意思是替买家开一个新账号，不是给已有账号续费。这两件事对买家的意义完全不同：续费是保住你原来的使用记录和配置，开新号是从零开始。

评价里的“15刀/月Premium”和官方 Premium $30/月 对不上。资料里没有解释这个差异的来源，可能是卖家自己的规格命名，也可能是别的什么，别把它当成官方折扣去推算。

下单前，这几件事要逐条问卖家，资料里都没有可核验的答案：

1. 账号归属：邮箱和密码归谁，能不能改成自己的邮箱。
2. 是否独享：有没有其他人同时登录同一个账号。
3. 掉线或封号怎么处理：补号、退款，还是不管。
4. 服务期限和续费价：这次付多少，下次续费多少。

## 三条路对比：官方订阅、代充、BYOK、号池网关

除了官方订阅和代充，还有两条技术路线，都是第三方工具，不是 Cursor 官方产品。

| 路线 | 你实际买到什么 | 钱付给谁 | 要自己动手的部分 | 已知代价 |
| --- | --- | --- | --- | --- |
| 官方订阅 | 对应档位的用量和功能 | Cursor | 有可国际支付的卡 | 第三方模型另计费；新订阅暂不支持支付宝 |
| 代充 | 一个账号或一段订阅期 | 卖家 | 提供信息、配合登录 | 账号归属、售后、续费价都不明 |
| 本地 BYOK 代理 | 自己 provider 的 API 额度 | 模型 provider | 装本地 CA、注入代理、维护更新 | 云索引能力受限，Cursor 更新前要先停插件 |
| 号池网关 | 本机账号或别人账号池的访问 | 网关或号池方 | 装 Cursor 插件和桌面工具 | 仓库不含源码，macOS 包未公证 |

本地 BYOK 代理（cursor-switch 这类工具）在本地起一个与 Cursor 兼容的 agent 服务，把 chat 和 agent 请求转发到你配置的模型 provider。它把三条控制面分开：身份、marketplace、登录走 Cursor 官方透传，用你的真实账号；订阅、套餐、用量在本地 mock 成无限制 Pro，避免真实套餐锁模型；模型推理走你自己的 key。支持 OpenAI 兼容接口和 Anthropic Messages API，内置 120+ 模型的定价表，成本统计能按日、按模型、按 provider 拆。

代价也具体：首次安装需要 UAC 提权，装本地 CA 证书并注入代理设置；@codebase、@docs、Repository Index 的真实向量检索依赖 Cursor 云索引，纯本地 BYOK 做不了，只能桩化登记或者切“直连 Cursor”透传；插件开着的时候 Cursor 自身更新会失败或被拦截，必须先停插件再更新。

号池网关（CGW 这类）是另一种形态：本机网关客户端，默认走你已登录的 Cursor 账号，需要时切到按需号池或自建网关。它由 Cursor 插件和桌面管理工具组成，桌面工具关掉窗口后本机服务仍在后台转发。插件侧栏能看到当前线路和消耗。仓库只放安装包，不含源码；macOS 包未做公证，首次打开会被系统拦下，需要去“隐私与安全性”点“仍要打开”，或者用命令去掉隔离标记。
